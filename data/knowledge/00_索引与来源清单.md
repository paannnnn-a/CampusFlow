## 三、RAG 检索设计建议

### 3.1 每个 chunk 建议带上的元数据字段
| 字段 | 取值示例 | 为什么需要 |
|---|---|---|
| `事务` | `学生证补办` | 路由到正确文档 |
| `校区` | `五山 / 大学城 / 广州国际校区 / 全校` | 三分校区的流程差异极大（报修、场馆、一体机位置） |
| `来源类型` | `制度原文 / 办事指南 / 通知公告 / 公众号` | 决定证据强度，制度原文优先 |
| `文号` | `华南工教〔2026〕22 号` | 精确定位，防止版本混用 |
| `生效/版本年份` | `2026 修订` | 学生手册每年换版，必须区分 |
| `是否含时限` | `true/false` | 用于"多久能办完"类问题 |
| `适用年级` | `2025 级及以后 / 全年级` | 辅修、转专业办法有年级限制 |

### 3.3 建议的系统提示（system prompt）片段
```
你是华南理工大学校园事务助手。回答规则：
1. 先判断校区（五山/大学城/广州国际校区），三分校区的办理入口与时限不同；用户未说明校区时，先说明差异再给答案。
2. 先判断年份/年级。学生手册每年改版，转专业（2026 修订）、辅修（2025 修订）、奖助（2024 修订）都有版本差异。
3. 涉及金额、时限、次数、分数线的，必须给出具体数字并注明出处文件名。
4. 搜索结果若同时出现"制度原文"与"办事指南/通知"，以制度原文为准；若两者冲突（如图书馆借书册数），指出差异并说明哪一版是现行。
5. 不要编造电话号码、窗口号、系统名称。资料中没有的，直接说"资料未涵盖，建议咨询×××"。
```

### 3.4 建议的文件切分粒度
- 按 `##` 二级标题切分（每份文档 8-10 个 chunk），单个 chunk 保持在 300-800 字。
- 每个 chunk 开头保留 `# 文档标题` 与 `> 一句话结论`，避免切片后丢失上下文。
- 「出处」章节单独成一段，作为可引用证据块。

1. **学籍证明**：学校没有独立的"学籍证明"办事页面，实践中以在读证明或学院开具的证明替代。文档中已明确说明。
2. **转专业当年报名通知**：每年报名时间、各院系接收计划以当年通知为准，本资料包只包含制度层面的流程。
3. **缓考申请表下载地址**：手册与学院指南均指向"教务处网站首页下载"，未定位到固定 URL。
4. **成绩单免费额度的"5 份/5 套"表述**：不同年份文件用词不同，已在文档中标注以系统显示为准。
5. **广州国际校区的部分细则**（体育场馆收费、功能房申请条件）来自公众号与通知，非制度原文。
