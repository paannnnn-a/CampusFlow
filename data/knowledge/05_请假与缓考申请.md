# 华南理工大学 · 请假与缓考申请

> 本文件用于 RAG 知识库。这是本次 10 项事务中**流程环节最多**的一项，涉及请假审批链、缓考审批链两个独立链条，请分开问、分开答。

## 1. 一句话结论

**请假**：按天数分级审批 —— ≤1 天由**班长同意 + 任课教师批准**；≤3 天由**班主任批准**；>3 天由**主管教学副院长批准**；均需报院（系）备案，**请假期满要按时销假**。
**缓考**：因病（附**二级甲等及以上医院证明**）或课程考试冲突，**考前**向所在院（系）和开课院（系）提出**书面**缓考申请，经**双方主管教学副院长批准**后方可参加下学期初的课程重考，该次成绩**不以"重考"标注**。

## 2. 请假制度（制度依据：《全日制本科学生学籍管理办法》第十六、十七条）

### 2.1 基本原则
- 学生应按时参加学校综合培养计划规定的**一切教学活动**。
- 因故不能参加的，**应当事先请假并获得批准**。
- **未经批准不参加教学活动者，视为旷课**。旷课学时以考勤记录为准（连续旷课以天计算，**旷课一天按 5 学时**计算）。
- 对旷课学生，依照《华南理工大学学生违纪处分办法》处理。

### 2.2 假期上限
| 假期类型 | 上限 | 附加要求 |
|---|---|---|
| 事假 | **最长不超过两周**（学生一般不准因私请事假） | 仅限特殊情况 |
| 病假 | **最长不超过一个月** | 须持有**医院开具的证明** |

### 2.3 分级审批链（关键表）
| 请假时长 | 申请主体 | 同意/批准人 | 备案 |
|---|---|---|---|
| ≤ 1 天（含 1 天） | 本人申请 | **班长同意** → **任课教师批准** | 报院（系）备案 |
| ≤ 3 天（含 3 天） | 本人申请 | **班主任批准** | 报院（系）备案 |
| > 3 天 | 本人申请 | **主管教学副院长批准** | 报院（系）备案 |
| 因病请假 ≥ 2 周 | 本人申请 | 经所在院（系）批准 | 报**本科生院**、**党委学生工作部（学生工作处）**备案 |

### 2.4 后续动作
- **销假**：请假期满要**按时销假**（销假不等于自动恢复考勤，一般需向批假人和辅导员报告已返校）。
- **超假后果**：未经批准擅自离校或超假**连续两周**未参加学校规定的教学活动者，除不可抗力等正当事由外，**予以退学处理**。
- **夜不归宿**：不履行请假手续而夜不归宿的，给予**警告处分**。
- **擅自离校累计**：未请假或请假未批准擅自离校，累计达 **7 日以上 14 日以下**的，按《学生违纪处分办法》相应条款处分。

### 2.5 请假流程（操作步骤）
1. 判断请假类型（事假/病假）与时长，对应找到批假人。
2. 填写请假申请（书面或系统，按学院要求），说明事由、起止时间、去向与联系方式。
3. 病假附**医院证明**（≥2 周须二级甲等或以上医院证明之要求见缓考条款；请假本身要求"医院开具的证明"）。
4. 按 2.3 表逐级取得同意/批准。
5. 报院（系）备案（≥2 周病假另报本科生院、学工部备案）。
6. 提前告知任课教师（尤其 ≤1 天档位需任课教师批准）。
7. 期满返校后办理**销假**。

## 3. 缓考制度（制度依据：《学籍管理办法》第三十条）

### 3.1 适用情形（两条，缺一不可）
1. **因病**：须附**二级甲等或以上医院证明**；
2. **课程冲突**：两门课程考试时间冲突。

> 学院办事页面对适用范围的另一表述："学生因病（附医院证明）或课程考试时间冲突，可申请课程缓考。**重修课程原则上不予以缓考**，如确有需要，需报本科生院教务科备案。"

### 3.2 办理时限要求
- 必须在**考前**提出（"应在考前向所在院（系）和开课院（系）提出书面的缓考申请"）。
- 缓考获准后参加**下学期初的课程重考**（与重考同批次报名、同批次考试），但该次成绩**不以"重考"标注**。
- 也可选择参加**课程重修**：对听课不作要求，但应参加考核，该次成绩**不以"重修"标注"**。

### 3.3 缓考审批链（5 个环节）
```
学生提交申请
  → 所在院（系）教务员审核
  → 所在院（系）教学副院长审核
  → 开课院（系）教务员审核
  → 开课院（系）教学副院长审核
```
（重修课程申请缓考，需**另送本科生院教务科备案**。）

### 3.4 缓考操作步骤（结合教务处的表格流转说明）
1. 下载并填写「**缓考申请表**」（教务处网站首页下载）。
2. 准备证明材料作为附件（医院证明 / 考试冲突证明 / 代表学校参加比赛的证明等）。
3. 找**任课老师**签意见并签名。
4. 到**学生所在学院**签字盖章。
5. 到**开课学院**签字盖章。
6. 将**缓考回执**交给任课老师（任课老师凭回执在成绩单上录"缓考"）。
7. **下学期初**（与重考一起）在**教务系统报名**，以获取考试资格。
8. 与重考一起**参加考试**（缓考）。

### 3.5 未办缓考的后果
- 未办缓考申请、或申请未被批准而**缺考者**，视为**缺考/旷考**。
- 必修课、专业选修课**首次考核不合格**者，可参加下学期初由开课院（系）安排的**课程重考**；重考仍不合格或未经批准擅自不参加考核者，**只能重修**，重修课程不能申请免修。
- 未经批准缺交作业累计超过总数 **1/3**，或缺课累计超过课程学时数 **1/3**，**取消该课程考核资格，必须重修**。
- 缓考通过的课程，其**绩点/百分制成绩可计算在修读学期**内（不因缓考而被剥离）。

- [ ] 开课学院签字盖章

## 5. 时限速查

| 事项 | 时限 |
|---|---|
| 请假申请 | **事先**（不能先走再补） |
| 事假上限 | 两周 |
| 病假上限 | 一个月 |
| 病假 ≥ 2 周的备案 | 院（系）批准 + 报本科生院、党委学生工作部备案 |
| 缓考申请 | **考前** |
| 缓考考试 | **下学期初**，与重考同批次 |
| 超假/擅自离校 | 连续 2 周未参加教学活动 → 退学处理 |

## 6. 常见问题与坑

- **Q：发烧了去不了考试，能直接不去吗？** 不能。必须先办**缓考**，否则按缺考处理。
- **Q：缓考要双方学院都签吗？** 是。**学生所在学院**和**开课学院**都需签，两边教务员和教学副院长各签一次。
- **Q：缓考的成绩会标"重考"吗？** 不会。缓考获准后参加下学期初的课程重考，该次成绩**不以"重考"标注**（这是缓考相对补考的关键优势）。
- **Q：重修课能缓考吗？** 原则上不行，确有需要须报本科生院教务科备案。
- **Q：请假 2 天找谁批？** 班主任（≤3 天档）。1 天以内找班长 + 任课教师。3 天以上找主管教学副院长。
- **Q：请假了还要销假？** 要。"请假期满要按时销假"，且超假连续两周未参加教学活动会被退学处理。
- **Q：让同学代签到行不行？** 不行。考勤以记录为准，代签属违纪，可能触发处分。
- **Q：高水平运动员请假有特殊规定吗？** 有。高水平运动员因比赛等特殊原因不能上课或考试，须**事先持体育学院书面证明**向所在院（系）提出因公请假；事先不办理或未获准假缺勤者按**旷课**处理。

## 7. 与相邻业务的衔接

- 缓考 → 若最终不及格，转入**课程重修**（教务系统报名）。
- 请假超期 → 可能触发《学生违纪处分办法》与退学处理，与**学籍管理**强相关。
- 因病长期无法学习 → 考虑**休学**（网上办事大厅"本科生休学申请"）。

## 8. 出处（可核验）

### 8.1 官方制度原文
1. **《华南理工大学全日制本科学生学籍管理办法》（2026 年手册版）**
   - 载体：《2026 年本科学生手册》第二部分，PDF 第 58-60 页（手册内页码 56-58）
   - 关键条款：
     - **第十六条**：教学活动出勤要求；未经批准不参加视为旷课；旷课一天按 5 学时计算。
     - **第十七条**：事假最长两周、病假最长一个月（须医院证明）；一天以内/三天以内/三天以上的分级审批；因病请假两周以上报本科生院与党委学生工作部备案；请假期满按时销假；超假连续两周予以退学处理。
     - **第二十九条**：必修课、专业选修课首次考核不合格可重考；重考不合格只能重修。
     - **第三十条**：因病（附二级甲等或以上医院证明）或课程冲突，考前向所在院（系）和开课院（系）提出书面缓考申请，经双方主管教学副院长批准；参加下学期初重考，成绩不以"重考"标注；也可参加重修。
     - **第三十一条**：缺交作业超 1/3 或缺课超 1/3，取消考核资格必须重修。
2. **《华南理工大学学生违纪处分办法》**
   - 载体：《2026 年本科学生手册》第二部分
   - 关键条款：不履行请假手续而夜不归宿的给予警告处分；未请假或请假未批准擅自离校累计 7 日以上 14 日以下按相应条款处分。
3. **《华南理工大学全日制本科高水平运动队管理办法》**
   - 载体：《2026 年本科学生手册》第二部分
   - 关键条款：高水平运动员须持体育学院书面证明事先因公请假；事先不办理或未获准假缺勤按旷课处理。

### 8.3 备注
- 手册版与国际校区版在"1 天以上 3 天以内"的表述上略有差异（手册为"三天（含三天）内由班主任批准"），**主体判断一致：≤1 天最轻、≤3 天班主任、>3 天副院长**。
