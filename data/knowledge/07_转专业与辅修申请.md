# 华南理工大学 · 转专业与辅修申请

> 本文件用于 RAG 知识库。转专业与辅修是两条独立路径，分别由不同文件规范；辅修又分「辅修专业」与「辅修学士学位」两个层次。

## 第 A 部分：转专业

### A1. 一句话结论

转专业有**四条通道**：① 新生二次选拔；② **自主转专业**（第二或第四学期，无未解除处分）；③ **帮扶转专业**（学习确有困难，第一学期第一周填表）；④ 其他情形（联合培养、教改班补选、休学创业/退役复学）。**第六学期及以后不得申请**。获准后**不得放弃、不得再次申请**。

### A2. 适用与禁止（制度硬性）

**不得转专业的四种情形（第三条）：**
1. 在**第六学期及以后**提出申请的；
2. 就读于**运动训练专业**的；
3. 通过**艺术类专业招生**办法录取，并申请转入**非艺术类专业**的；
4. 招生时确定为**定向培养**或享受**定向奖学金**的学生，以及国家有相关规定或录取前与学校有明确约定不可转专业的学生。

**适用范围（第九条）：** 五山校区、大学城校区本科学生（含港澳台地区本科生）；**广州国际校区**学生转专业办法另行制定。

### A3. 四条通道与各自流程

#### 通道① 新生转专业（新生二次选拔）
- 适用：新生入学阶段，参加**教学改革班**及**广州国际校区各专业新生二次选拔**的学生。
- 流程：按**当年新生二次选拔通知**要求的程序，被录取的学生办理转专业手续，转入新专业学习。

#### 通道② 自主转专业（绝大多数人走这条）
- 条件：**无任何未解除的纪律处分**；可于**第二或第四学期**依据本人学习兴趣和专长申请。
- 接收计划：各专业接收计划数依专业建设规划、招生规模、教育教学资源与办学条件确定；接收院（系）自行发布**自主转专业接收学生工作方案**，公开、公平、公正**择优录取**。接收院（系）可决定是否**降级转入**。
- **流程 4 步：**
  1. 各院（系）制订"院（系）自主转专业接收学生工作方案"（工作原则、组织领导、接收计划和条件、选拔考核、选拔安排），报**本科生院审核**后向全校公布；各院（系）成立转专业考核工作小组并指定咨询人员。
  2. 学生**在规定时间登录学校教务管理系统报名并确认提交**，**逾期不予受理**。
  3. 转入院（系）依方案全面考核，将拟接收名单及材料**公示 7 天**，无异议后报本科生院。
  4. 本科生院复核后报**主管校领导审批**。

#### 通道③ 帮扶转专业
- 两种可申请情形（满足其一）：
  1. 入学后发现某种**疾病或生理缺陷**，经**二级甲等及以上医院或相关专科医院**检查证明，并经**学校医院复核**，不能在原专业学习，但尚能在本校其他专业学习；
  2. 对所学专业**不感兴趣且学习成绩较差**，继续原专业学习确有困难。
- **附加门槛：** 高考分数**不得低于**申请转入专业该生高考当年当地高考录取分数线；**高考科类为文科的学生不能转入理工类专业**。
- **流程 3 步：**
  1. **每学年第一学期第一周**，学生填写《华南理工大学本科学生转专业申请表（帮扶）》，按申请理由备好支撑材料，**分别提交转出院（系）和转入院（系）审核**。
  2. 转出院（系）审核材料真实性，由**分管学生工作的党委副书记与分管教学负责人共同签署意见**；转入院（系）组织**专家面试、考核**，同样由党委副书记与分管教学负责人共同签署意见。两院（系）均同意后，材料由**转出院（系）**报送本科生院。
  3. 本科生院复核后报**主管校领导审批**。

#### 通道④ 其他转专业（按转专业处理，无需自主申请考核）
1. 参加学校与国（境）外高水平大学联合培养学位项目，因国内外专业设置差异，原专业与国（境）外专业在**同一学科大类而具体专业不符**的学生；
2. 参加学校各类**教学改革班补充遴选**的学生；
3. **休学创业或退役后复学**，因自身情况需要转专业的学生；
4. 根据学校其他规定允许转专业的学生。

### A4. 获准后的强制事项

- **第五条**：获准转专业的学生**原则上不得放弃**；已办理转专业者，**不允许再次申请**。
- **第六条**：按《华南理工大学本科学生转专业报到指南》办理**学籍调整、注册**；到新专业报到后**1 个月内**完成**转入专业课程学分认定**手续（依《华南理工大学全日制本科学生校内学分认定实施办法》）。
- **第七条**：当学年起按**转入专业、年级的学费标准**缴费。
- **第八条**：转专业过程中有违规行为的，依规处理；**有违纪行为的学生取消转专业资格并给予处分**；纪检监察部门实施再监督。

### A6. 常见问题与坑

- **Q：大三（第五学期）还能转吗？** 第五学期尚可（第六学期及以后不可），但自主转专业限定在**第二或第四学期**申请，实际窗口很窄。
- **Q：有处分能转吗？** 有**未解除**的纪律处分不能自主转专业。
- **Q：转专业要考试吗？** 自主转专业由接收院（系）按自订方案考核（笔试/面试/材料，各院系不同）；帮扶转专业需**专家面试考核**。
- **Q：能转两次吗？** 不能。"已办理转专业者，不允许再次申请转专业"。
- **Q：录取了能放弃吗？** 原则上不得放弃。
- **Q：转完专业学分怎么办？** 报到后 **1 个月内**完成学分认定，具体依校内学分认定办法。
- **Q：广州国际校区的学生按这个办法吗？** 不按，另行制定。

## 第 B 部分：辅修专业与辅修学士学位

### B1. 一句话结论

辅修可在**入学后第二学期**开始申请，在校期间**只能申请一个辅修专业或一个辅修学士学位**；通过**教务管理系统报名 + 选课缴费**；**辅修专业 ≥ 20 学分**，**辅修学士学位 ≥ 45 学分**（含毕业设计/论文 6 学分）。

### B2. 基本规则（制度原文要点）

- **第二条**：辅修须在本科学习阶段完成；辅修专业应与主修专业归属**不同的本科专业类**；分**辅修专业**与**辅修学士学位**两个层次。
- **第三条**：已有一届全日制本科毕业生的专业，院（系）可申请开设辅修并报**教务处审批**；辅修培养方案依同专业本科培养方案制定，经教务处审核后实施。
- **第四条**：四年制专业辅修教学活动安排在**第二至八学期**；五年制专业安排在**第二至十学期**。
- **第五条**：主修与辅修教学活动冲突时，**服从主修专业安排**。
- **第六条**：**入学后第二学期**开始申请；在校期间**只能申请一个**辅修专业或辅修学士学位。
- **第七条（申请条件）**：主修专业**学有余力**，**未受学业预警或降级试读**处理。
- **第二十条**：仅适用于**五山校区、大学城校区**本科学生（广州国际校区另行制定）。
- **第二十一条**：适用于 **2025 级及以后**入学本科学生，教务处负责解释。

### B3. 申请程序（第八条，三步）

1. 开设辅修的院（系）提出**招生计划**，经**教务处批准**后在**教务处主页公布**；
2. 学生在**学期末规定时间内**通过**教务管理系统报名**；教务处负责审查资格。除**更换辅修专业**外，**已报名学生后续无需重复报名**；
3. 学生在**学期末规定时间内**登录教务管理系统**选课并缴纳辅修课程费用**，下学期开学初按所选课程安排开始辅修学习。

### B4. 费用

- **第九条**：辅修课程按**学分收费**，收费标准依学校财务有关收费标准执行。

### B5. 成绩与学籍管理（易被问到的细节）

| 条款 | 规定 |
|---|---|
| 第十条 | 辅修课程教学计划与成绩由**辅修专业所在院（系）**管理；辅修毕业资格由辅修院（系）审核 |
| 第十一条 | 主修与辅修存在**学分相同、内容相近**课程（跨学院选课课程除外），取得主修学分后可申请认定；**认定总学分不得超过**辅修专业/辅修学士学位总学分的 **20%** |
| 第十二条 | 辅修课程**不及格不得重考**，必须**重修并缴费** |
| 第十三条 | 主修受**学业预警或降级试读**处理，**下一学期暂停辅修资格**，解除后可申请继续 |
| 第十四条 | 自动退学/受退学处理：按主修专业开退学证明和**肄业证书**；受开除学籍处分：按主修专业开**学习证明** |
| 第十五条 | 因故终止辅修、未取得证书，可申请将已获辅修学分认定为**相近通识课或主修方案外选修课**学分 |
| 第十九条 | 主修毕业资格审查为**结业/肄业/延长学籍**，**终止辅修资格**，学分认定按第十五条 |

### B6. 学分与学位要求（关键数字）

- **第十六条**：辅修专业毕业要求 **≥ 20 学分**；辅修学士学位要求 **≥ 45 学分**，其中辅修学士学位**毕业设计（论文）6 学分**（含毕业实习）。
- **第十七条（进入辅修学位阶段的门槛）**：前六学期（五年制前八学期）主修专业**必修课平均成绩 ≥ 75 分**，且所修辅修学士学位课程学分（含在修）**超过**培养方案要求总学分的 **80%**，经教务处审批于**第七学期**（五年制第九学期）进入辅修学士学位修读阶段。
- **取消辅修学士学位资格的三种情形**（按辅修专业处理）：
  1. 辅修学士学位**毕业设计（论文）未通过**；
  2. **第八学期**（五年制第十学期）结束前未完成全部课程并取得学分；
  3. 主修**只获得毕业证书，未获得学士学位证书**。

### B7. 证书与学位（第十八条）

- 取得主修毕业资格 + 修完辅修学士学位培养方案课程并取得学分 → 颁发**辅修专业证书**；
- 获得主修学士学位 + 符合学校授予辅修学士学位规定，经**学校学位评定委员会**审议通过 → 授予**辅修学士学位**；
- **辅修学士学位在主修学士学位证书中注明，不单独发放学位证书**（这是高频误解点）。

### B8. 常见问题与坑

- **Q：辅修和转专业能同时搞吗？** 制度上未禁止，但辅修要求"主修学有余力、未受学业预警"，且主辅冲突时服从主修，实际不建议并行。
- **Q：辅修挂科能补考吗？** **不能重考**，只能**重修并缴费**。
- **Q：辅修学位会单独发一张学位证吗？** **不会**，只在主修学士学位证书上注明。
- **Q：我已经报名过，下次还要再报吗？** 除**更换辅修专业**外，已报名学生**无需重复报名**；但每学期**选课与缴费**仍需在规定时间完成。
- **Q：主修被学业预警了还能辅修吗？** 下一学期**暂停**辅修资格，预警解除后可申请继续。
- **Q：辅修学分能抵主修吗？** 只能反向操作：主修课程可认定为辅修课程，且认定总量 ≤ 辅修总学分的 20%。
- **Q：辅修要读几年？** 教学活动安排在第二至八学期（五年制第二至十学期），即在正常学制内完成，不额外延长。
