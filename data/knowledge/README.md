# 校园知识文档目录

本目录存放 `search_campus_knowledge` 检索用的校园办事资料。**文件由 B 依据真实通知整理**，
不做自动抓取，也不编造政策内容。

## 为什么要求标注来源

CampusFlow 的验收要求「知识问答附有依据」，且明确「学校官方系统不开放时，
使用明确标注的模拟数据，不声称已完成官方操作」。因此每篇文档必须在文件头
（front matter）声明来源属性，否则：

- 缺 `source_type` → 按 `simulated` 处理（保守，不会误标为官方）；
- `source_type` 只接受 `simulated` 或 `official`，其他值直接报错拒绝加载。

## 文件格式

推荐 Markdown，一个事务一个文件（也可一份通知一个文件）。示例：

```markdown
---
title: 学生证补办流程
source_id: 学生证补办
source_type: simulated
source: 依据 XX 大学学生手册第 12 条整理（本仓库为模拟整理）
url:
updated_at: 2026-10-01
---

## 适用情形

...

## 所需材料

- 身份证原件与复印件
- 一寸证件照两张

## 办理步骤

1. ...
2. ...
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 展示给用户的文档标题 |
| `source_id` | 否 | 引用编号；缺省用文件名。会出现在答复的 `[source_id]` 中 |
| `source_type` | 否 | `simulated`（默认）或 `official` |
| `source` | 否 | 文档出处，缺省为「未标注来源」并在答复中提示 |
| `url` | 否 | 原始网页或文件地址 |
| `updated_at` | 否 | 文档日期，`YYYY-MM-DD` |

## 写作建议

切成什么粒度直接决定检索效果。本项目按**标题 + 段落**切分，因此：

1. **用 `##` 分节**，一节讲一件事（适用情形 / 所需材料 / 办理步骤 / 注意事项）。
2. **清单用列表**：连续的 `-` 或 `1.` 列表项会保留在同一个片段里，
   不会被切成互相独立的短句（这是本项目切分器的特殊处理）。
3. **一节不要超过 400 字**，超长会自动按句子切分并加入重叠。
4. **标题用问句里的词**：用户常问「需要哪些材料」，标题就叫「所需材料」，
   检索会因标题命中而显著提权。

## 支持格式

| 格式 | 处理方式 |
|---|---|
| `.md` / `.markdown` | 按标题切分，保留标题路径 |
| `.txt` | 按空行分段 |
| `.pdf` | 按页提取文本后分段，记录页码（需 `pip install pypdf`） |

文件须为 **UTF-8** 编码。

## 入库

```bash
python -m backend.rag.cli rebuild      # 重建索引
python -m backend.rag.cli stats        # 查看统计
python -m backend.rag.cli search 学生证丢了怎么办
```

索引写入 `data/chroma_db/`（不提交 Git）。未安装 `chromadb` 时会自动回退到内存索引，
可正常跑测试，但重启后失效。
