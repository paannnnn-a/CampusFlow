# 第三版：真实百炼联调修复

已使用本地配置实际连接百炼 qwen-plus，基础工具调用与结果回传成功。发现并修复以下问题：

- 百炼在非流式 tool_calls 中附带 index 等字段，HTTP 适配器现在只提取工具协议必需字段后交给严格校验。
- Windows 旧版 pip 以 GBK 读取 requirements 时无法解析中文注释，依赖文件注释已改为 ASCII。
- 后端计算今天、明天与下一自然周的起止日期，避免模型把下周理解为明天起七天。
- 明确缺少日期时补问；用户明确委托预约/报名时提出写工具调用，由后端暂停确认。
- 校园事务先获取知识依据和办理字段；保留用户已提供的遗失原因，不要求用户补充学校政策。
- Mock 活动检索支持空格或逗号分隔的多个关键词。
- 办理要求和草稿工具按本轮已完成的前置查询逐步开放；执行前再次校验，不能绕过知识检索。
- 新增不依赖记事本的本地 configure_key.py。

回归测试：103 项全部通过。真实模型校园场景结果见 evaluation_llm.json；模型仍可能随提示词和服务端版本变化，需要持续验收。业务仍为 Mock，不代表 B/C/D 或学校官方系统已接入。
